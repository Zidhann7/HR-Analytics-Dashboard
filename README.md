# HR-Analytics-Dashboard In Excel
HR Analytics Dashboard in Excel

I recently developed an HR Analytics Dashboard using Excel to analyze employee data and generate meaningful business insights.

### Key areas covered:

* Total Employees and Attrition Rate
* Average Salary and Experience
* Employee Satisfaction Analysis
* Attrition by Department and Job Role
* Relationship between Salary and Attrition

### Key insights:

* Identified departments with higher attrition rates
* Observed correlation between low satisfaction and employee turnover
* Analyzed the impact of salary and experience on retention

### Tools and techniques used:

* Microsoft Excel
* Pivot Tables and Pivot Charts
* Slicers for interactive filtering
* Data cleaning and transformation

### Outcome:
This dashboard provides a structured view of workforce data, enabling better decision-making in employee retention, performance management, and workforce planning.
